=== Webhook Configuration ===

To get the webhook URL, run:

{{- if eq .Values.triggers.eventListener.serviceType "LoadBalancer" }}

  export WEBHOOK_URL=$(kubectl get svc {{ .Values.triggers.eventListener.name }} \
    -n {{ .Values.namespace.name }} \
    -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
  echo "Webhook URL: http://${WEBHOOK_URL}:{{ .Values.triggers.eventListener.servicePort }}"

{{- else if eq .Values.triggers.eventListener.serviceType "NodePort" }}

  export NODE_PORT=$(kubectl get svc {{ .Values.triggers.eventListener.name }} \
    -n {{ .Values.namespace.name }} \
    -o jsonpath='{.spec.ports[0].nodePort}')
  export NODE_IP=$(kubectl get nodes -o jsonpath='{.items[0].status.addresses[0].address}')
  echo "Webhook URL: http://${NODE_IP}:${NODE_PORT}"

{{- else }}

  kubectl port-forward svc/{{ .Values.triggers.eventListener.name }} \
    -n {{ .Values.namespace.name }} 8080:{{ .Values.triggers.eventListener.servicePort }}

  Then use: http://localhost:8080

{{- end }}

Configure your Git webhook with:
- Payload URL: <webhook-url-from-above>
- Content type: application/json
- Events: Push events
- Branch filter: {{ .Values.triggers.github.branches | join ", " }}

{{- end }}

=== Manual Pipeline Run ===

To manually trigger the pipeline:

  kubectl create -f - <<EOF
  apiVersion: tekton.dev/v1beta1
  kind: PipelineRun
  metadata:
    generateName: {{ .Values.pipeline.name }}-manual-
    namespace: {{ .Values.namespace.name }}
  spec:
    pipelineRef:
      name: {{ .Values.pipeline.name }}
    serviceAccountName: {{ .Values.serviceAccount.name }}
    params:
      - name: git-url
        value: "{{ .Values.git.url }}"
      - name: git-revision
        value: "{{ .Values.git.revision }}"
      - name: image-name
        value: "{{ .Values.docker.imageName }}"
      - name: image-tag
        value: "manual-$(date +%Y%m%d-%H%M%S)"
    workspaces:
      - name: shared-workspace
        volumeClaimTemplate:
          spec:
            accessModes:
              - ReadWriteOnce
            resources:
              requests:
                storage: 1Gi
      - name: gradle-cache
        {{- if .Values.gradle.cacheEnabled }}
        persistentVolumeClaim:
          claimName: gradle-cache-pvc
        {{- else }}
        emptyDir: {}
        {{- end }}
      - name: docker-credentials
        secret:
          secretName: {{ .Values.ncr.credentials.secretName }}
  EOF

=== Monitor Pipeline ===

Watch pipeline runs:
  kubectl get pipelinerun -n {{ .Values.namespace.name }} -w

View logs:
  tkn pipelinerun logs <pipelinerun-name> -f -n {{ .Values.namespace.name }}

Or with kubectl:
  kubectl logs -f <pod-name> -n {{ .Values.namespace.name }}
